# AutoPilot — Панель управления

Это файл-панель управления автопилотом. Двигатель читает его перед каждой итерацией.

## Флаг состояния

```
FLAG: RUN
```

Возможные значения:
- `RUN` — работать (выполнять задачи из очереди)
- `PAUSE` — пауза (не запускать новые задачи, но двигатель жив)
- `STOP` — полная остановка (двигатель завершит цикл)

## Бюджет токенов

```
TOKEN_BUDGET: 300000
TOKENS_SPENT: 0
```

`TOKEN_BUDGET` — максимум токенов за кампанию. `TOKENS_SPENT` — уже потрачено (обновляет двигатель). Когда `TOKENS_SPENT >= TOKEN_BUDGET`, двигатель автоматически ставит `STOP`.

## Модель

```
MODEL: opencode-go/deepseek-v4-flash
```

Двигатель всегда запускает задачи на этой модели (если она доступна).

## Статус последнего цикла

```
LAST_RUN: не запускался
LAST_TASK: —
LAST_RESULT: —
```

## Правила работы

1. Двигатель берёт первую невыполненную задачу `- [ ]` из `AUTO_TASKS.md`.
2. Запускает opencode headless с промптом задачи, работает в git-ветке `autopilot`.
3. После завершения коммитит изменения и помечает задачу `- [x]` в очереди.
4. Спящий режим между задачами — `AUTOPILOT_INTERVAL_SEC` в `scripts/autopilot.ps1`.
