# Предрелизный аудит v3 — Решение по критическим фиксам

#review #decision

**Дата:** 18.07.2026
**Контекст:** Третье критическое ревью (v3) — аудит закрытия проблем из v1+v2. Проверка утверждения CURRENT_TASK.md «16/16 выполнено» против реального кода.

## Найдено — 5 критических блокеров релиза

1. **CombatFacade.js — missing imports** (`CombatFacade.js:61,71,72`). Вызовы `isHost()` и `getMyId()` без импорта из `network.js`. Мультиплеер падает с ReferenceError.
2. **Квест `cursed_temple` невыполним** (`quests.js:597`). Цель `corrupted_priest` отсутствует в `CURSED_ENEMY_TYPES` (`enemies.js:215-221`). Квест висит вечно, блокирует следующий.
3. **Synergy DMG бафф сеттится, но не применяется** (`SpellSystem.js:92` сеттит `_synergyDmgBuff = 0.3`, `GameScene.js:685-689` декрементит таймер, но **ни один файл не читает этот бафф в формуле урона**).
4. **Prestige: 6 из 10 уровней — косметика** (`prestige.js:7-18` — эффекты `lifesteal`, `critBonus`, `damageReduction`, `spellCooldownReduction`, `goldBonus`, `dodgeChance` не имеют реализации; `lootBonus` тоже).
5. **Финал: нет выбора, нет объяснения Prestige** (`ThroneZone.js:145-256`). Текст на 12 секунд, игрок уходит в портал, Prestige разблокирован молча.

## Решения

### Fix 1: CombatFacade imports
Добавить `import { isHost, getMyId } from '../network.js';` в `CombatFacade.js`.
**Обоснование:** Обе функции уже экспортируются, используются в 5+ других файлах. 1 строка.

### Fix 2: cursed_temple
Заменить `target: 'corrupted_priest'` → `target: 'dark_priest'` в `quests.js:597`.
**Обоснование:** `dark_priest` уже входит в `CURSED_ENEMY_TYPES` как healer с полным набором (ключ, спрайт bog_witch, анимация). Создавать нового врага ради одного квеста неоправданно для v1.

### Fix 3: Synergy DMG
Добавить чтение `s._synergyDmgBuff` в `CombatCore.hitEnemy()` (перед блоком combo).
**Обоснование:** 4 строки. Бафф уже сеттится, таймер уже декрементится — не хватает только потребления в формуле урона.

### Fix 4: Prestige trim — ВАРИАНТ A (обрезать до 3 работающих уровней)
Удалить уровни 3-9 из `prestige.js`, оставить: Glass Cannon (1), Speed Demon (2), Ascended (3→бывший 10). `maxLevel: 10` → `maxLevel: 3`.
**Обоснование выбора A вместо B:**
- Вариант B (доделать все 10) требует ~4 часа работы в 4 файлах (`CombatCore`, `CombatLoot`, `PlayerSystem`, `SpellCast`) и несёт риск багов в формулах баланса (dodge 20% + DR 20% = 36% EHP).
- Для v1 достаточно 3 уровней: 1.5^x scaling даёт 5x сложность на макс. уровне. Полноценные 10 уровней — на v2.

### Fix 5: Финальная сцена с выбором
Добавить метод `_showFinaleChoice()` в `ThroneZone.js`: панель с тремя кнопками (Prestige / Continue / Menu), локализация через inline trilingual объекты (паттерн `localStorage.getItem('game_lang')` как во всём проекте), keyboard + mouse support.
**Обоснование:** Игрок, прошедший 15 зон, не должен гадать что делать дальше. Минимальный выбор замыкает цикл.

## Сознательно отложено на v2

| Проблема | Причина отложения |
|----------|-------------------|
| Depths: ложный выбор пути (двери Armory/Library/Crypt) | Не влияет на прохождение, можно убрать или доделать |
| Lore-предметы только в Лесу (контент для 10 зон написан) | Не блокирует игру, контент готов — нужен только вызов spawn |
| Host migration (PeerJS P2P) | Ожидаемо для инди-preview v1 |
| GameScene God Object (731 строка, 105 методов) | Не видно игроку, рефакторинг не даст ценности для v1 |
| Temple-биом (спрайты, анимации без зоны) | Orphaned assets из раннего прототипа |
| Дубли IceSpirit босса (SnowyZone + IceSpiritBoss) | Оба работают, дедупликация — технический долг |
| Бесконечный фарм в Лесу/Шахте (мобы респавнятся каждые 3с) | Для v1 это скорее плюс — игроки не застревают |
| Prestige enemies Void Wraith + Blood Golem (спрайты есть, spawn-кода нет) | Часть полноценной Prestige v2 |
