# Конвенция: Config-driven design

#convention #config #data

**Дата:** 2026-07-21

## Summary

Все игровые параметры (здоровье, урон, шансы, награды, текстуры врагов) хранятся в `src/config/*.js`. В коде не должно быть магических чисел — только обращения к конфигу.

## Правило

```
Новый параметр → сначала config → потом код
```

Нельзя:
```js
// ❌ Магическое число в коде:
if (enemy.stats.hp < 50) { ... }
const damage = player.level * 15;
```

Нужно:
```js
// ✅ Значение из конфига:
import { BALANCE } from '../config/balance.js';
if (enemy.stats.hp < BALANCE.LOW_HP_THRESHOLD) { ... }
const damage = player.level * BALANCE.DMG_PER_LEVEL;
```

## Структура `src/config/`

| Файл | Содержит |
|------|----------|
| `index.js` | Реэкспорт всех данных |
| `enemies.js` | Типы врагов по зонам (ENEMY_TYPES, CAVE_ENEMY_TYPES, ...) |
| `zones.js` | Размеры зон, позиции лагерей, константы |
| `items.js` | Все предметы: оружие, броня, аксессуары, зелья |
| `spells.js` | Заклинания, улучшения, привязка к классам |
| `crafting.js` | Рецепты крафта |
| `quests.js` | Квесты с наградами |
| `pets.js` | Питомцы (12 шт), редкости, типы |
| `talents.js` | Данные талантов (47×3 class + 70 account) |
| `balance.js` | Константы баланса (криты, уклонение, скорость) |
| `difficulty.js` | Множители по сложностям |
| `rarity.js` | Цвета, множители, звёзды по редкостям |
| `gold.js` | Золотые дропы, консьюмаблес, магазин |
| `prestige.js` | Prestige уровни и эффекты |
| `sets.js` | Сетовые бонусы (27 сетов) |
| `animations.js` | Конфиги анимаций |
| `ui.js` | Цвета и размеры UI |
| `intro.js` | Тексты интро |
| `lore.js` | Тексты лора по локациям |
| `mapData.js` | Данные для карты |
| `systemQuests.js` | Системные квесты |

## Исключения

Допустимо хардкодить:
- Константы UI (размеры шрифтов, отступы) — если они используются один раз
- Значения по умолчанию в fallback-ветках
- Тестовые данные

## Когда применяется

- Добавление нового типа врага → `enemies.js`
- Добавление нового предмета → `items.js`
- Изменение баланса → `balance.js` или `difficulty.js`
- Добавление нового питомца → `pets.js`
