# AutoPilot — вечный двигатель для Loot Realms

Автономная работа: opencode сам берёт задачи из очереди, выполняет их,
коммитит результат и переходит к следующей — пока не исчерпает бюджет токенов
или ты не скажешь STOP.

## Как устроено

```
AUTO_TASKS.md   — очередь задач (двигатель берёт первую - [ ] сверху)
AUTO_CONTROL.md — панель управления (флаг RUN/PAUSE/STOP + бюджет токенов)
scripts/autopilot.ps1 — сам двигатель (бесконечный цикл)
scripts/autopilot.log — журнал работы
```

Двигатель:
1. читает `AUTO_CONTROL.md` (флаг, бюджет, модель)
2. берёт первую невыполненную задачу из `AUTO_TASKS.md`
3. запускает её в headless opencode (модель `opencode-go/deepseek-v4-flash`)
4. коммитит результат в git-ветку `autopilot`
5. помечает задачу `- [x]`, спит N секунд, повторяет

## Запуск

```powershell
# из корня проекта, в любой консоли:
powershell -NoProfile -ExecutionPolicy Bypass -File scripts\autopilot.ps1 -IntervalSec 1800
```

- `-IntervalSec` — пауза между задачами в секундах (по умолчанию 1800 = 30 мин).
- `-TaskTimeoutMin` — лимит времени на одну задачу (по умолчанию 20 мин). Если задача
  превышает лимит или не даёт прогресса 5 минут — сессия прерывается, задача
  помечается пропущенной, двигатель идёт дальше.
- Для запуска в фоне: `Start-Process powershell -ArgumentList '-NoProfile','-ExecutionPolicy','Bypass','-File','scripts\autopilot.ps1','-IntervalSec','1800' -WindowStyle Hidden`
- Пароль сервера берётся из `OPENCODE_SERVER_PASSWORD` (или передай `-ServerPass`).

## Наблюдатель за ботом (необязательно)

Если демон Telegram-бота завис (процесс жив, но нет соединений), он не отвечает.
Лёгкий наблюдатель `scripts\watch-bot.ps1` раз в 5 минут проверяет бота и
перезапускает, если тот завис:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts\watch-bot.ps1
```

- Потребляет почти ничего (одна проверка в 300 сек).
- **Не вмешивается**, если процесс бота полностью отсутствует — то есть ты
  сам его убрал, наблюдатель не мешает твоему контролю.
- Запускается вручную (в автозапуске нет).

## Автозапуск

Автозапуск сервера/бота **отключён** (удалён из Startup). Всё запускаешь сам:
- Сервер: `opencode serve --port 4096`
- Бот: `opencode-telegram start --daemon`
- Наблюдатель: `scripts\watch-bot.ps1`
- Автопилот: `scripts\autopilot.ps1`

## Управление (в т.ч. с телефона)

Всё управление — через файл `AUTO_CONTROL.md` в корне проекта:

| Хочешь | Что сделать |
|--------|-------------|
| Работать | `FLAG: RUN` |
| Пауза (после текущей задачи) | `FLAG: PAUSE` |
| Полный стоп | `FLAG: STOP` |
| Сменить лимит токенов | `TOKEN_BUDGET: 300000` |

С телефона (через бота `@ppptrbot`): напиши боту сообщение вида
`измени AUTO_CONTROL.md: поставь FLAG: PAUSE` — бот отправит его в opencode,
агент отредактирует файл, двигатель увидит на следующей итерации.

## Добавление задач

Отредактируй `AUTO_TASKS.md` — добавь строку `- [ ] описание задачи` в секцию
`## Задачи`. С телефона: напиши боту `добавь в AUTO_TASKS.md задачу: <текст>`.

## Ограничения (важно!)

Агент обязан соблюдать `AGENTS.md`. **Запрещено** без явного запроса:
- добавлять новые игровые механики
- менять баланс вне `src/config/`
- удалять/переименовывать файлы без обоснования

Разрешено: рефакторинг, баги, документация, тесты, оптимизация.

## Проверка статуса

- `AUTO_CONTROL.md` → секция «Статус последнего цикла» (последняя задача, токены)
- `scripts\autopilot.log` → полный журнал
- `git log` → все автокоммиты в ветке `autopilot`
