# BLACK PILL REVIEW V2 — Loot Realms

> Повторный аудит после Phase A фиксов
> Дата: 2026-07-23

---

## 1. Вердикт одним абзацем

**Loot Realms** превратился из прототипа без первой минуты в проходимую игру с началом, серединой и концом — но только для игрока, готового мириться с процедурной графикой, oscillator-звуком и UI-багами. Первые 30 секунд теперь работают: игрок спавнится в Meadow, получает меч, guided tutorial ведёт за руку через движение → NPC → ворота → лес → сундук → 3 убийства → портал на босса. Это гигантский скачок от v1. Но игра всё ещё проигрывает indie-конкурентам в трёх измерениях: game feel, визуальная идентичность и глубина боя. Игрок дойдёт до Arena, убьёт Treant — и скорее всего выйдет, потому что после босса нет понятной причины продолжать.

---

## 2. Главная BLACK PILL V2

**Фундаментальная проблема больше не "нет туториала". Новая: после Arena нет hook'а на следующие 14 зон.**

Игрок проходит Meadow → Forest → Arena → убивает Treant. Дальше открывается Mine. Но:
- `CombatLoot.killBoss()` просто показывает "BOSS DEFEATED!" + лут-текст.
- Нет сюжетного момента "Амулет заряжен, иди в Шахту".
- Нет изменения мира (Meadow NPC не обновляет диалог).
- Нет cutscene или письма/предмета, который объясняет "почему именно Шахта".
- `zoneFlags.forestCleared` не сеттится.

Игрок видит: "Ну, убил босса. Дальше шахта, наверное?" — и идёт, потому что нечего другого делать. Это называется **"passive progression"**: игрок двигается, потому что карта открыта, а не потому что хочет. Результат: retention падает после 15-20 минут.

## 5. Что всё ещё необходимо удалить или упростить

- **Corruption** — полностью удалить из кода (не только из HUD). Механика отключена из game loop, код висит мёртвым грузом в 6+ файлах.
- **Multiplayer bundle** — вынести `peerjs` и `firebase` в динамический импорт. Сейчас 427 KB в бандле за фичу, которую никто не видит.
- **Account equip из лут-пула мобов** — `ACCOUNT_EQUIP_DROP_CHANCE = 0.001` для обычных врагов. Лишний спам в инвентарь.
- **Meadow auto-sword** — убрать авто-выдачу, давать через NPC диалог.

## 6. Недостающий игровой цикл (V2)

### Текущий после фиксов:
```
Meadow (safe) → авто-меч → guided: движение → NPC → gate →
→ Forest → guided: движение → chest → 3 kills → portal →
→ Arena → бой с Treant → "BOSS DEFEATED!" → лут-текст →
→ игрок стоит в Arena с вопросом "what now?" →
→ Portal в Mine (или в Menu по exit)
```

### Улучшенный:
То же самое, **но после Arena**:
```
→ Босс убит → slow-mo + zoom → "ARENA CONQUERED" (3 сек) →
→ Амулет Возврата (quest item dropped) →
→ Авто-возврат в Meadow → NPC обновляет диалог:
  "Ты сделал это! Амулет заряжен. Шахта теперь открыта — там ключ от Врат Деревни."
→ Quest marker "Mine" появляется на UI →
→ mine_gate в Meadow открывается (новая текстура) →
→ Игрок идёт в Mine с понятной целью.
```

## 9. Тестирование игроками (V2)

Тот же сценарий, что в V1, плюс:
- Доходит ли игрок до Arena? (проходит ли guided tutorial)
- Нажимает ли Continue после смерти или закрывает игру?
- Понимает ли, куда идти после Arena?
- Открывает ли инвентарь? Экипирует ли лут с босса?

**Критерии провала дизайна V2:**
- Игрок не доходит до Arena (не прошёл guided tutorial) → туториал сломан
- Игрок умирает и закрывает игру на экране смерти → death penalty слишком жёсткая или экран страха
- Игрок убивает Treant и выходит в течение 2 минут → нет hook после босса

## 10. Финальный приоритет (V2)

**Если разработчик может сделать только три вещи прямо сейчас:**

1. **Hook после Arena** — NPC в Meadow обновляет диалог + quest marker на Mine. Без этого игрок не понимает, зачем играть дальше 15 минут.

2. **Босс-килл с экраном "ARENA CONQUERED"** — slow-mo + zoom + 3 сек паузы. Без этого убийство Treant — очередной beep.

3. **Протестировать все 14 зон** — хотя бы пройти от Meadow до Throne один раз. В CURRENT_TASK.md висит как "Next Steps" с момента создания. Реальные баки в зонах 5-14 могут оказаться блокерами.

Всё остальное — звук, графика, сравнение предметов, мультиплеер — можно делать после того, как игра проходится от начала до конца.
