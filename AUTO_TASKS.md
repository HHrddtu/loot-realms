# AutoPilot — Очередь задач

Двигатель берёт задачи сверху вниз. Формат строки: `- [ ] описание задачи`.

## Как добавить задачу

- Напрямую отредактировать этот файл (на компьютере)
- Через бота `@ppptrbot`: отправить сообщение вида `добавь в AUTO_TASKS.md задачу: ...`

## Ограничения для агента

> [!DANGER]
> Агент обязан соблюдать `AGENTS.md` проекта. **Запрещено** без явного запроса:
> - добавлять новые игровые механики (defense waves, боссы, зоны, системы)
> - менять баланс и magic numbers вне `src/config/`
> - удалять или переименовывать существующие файлы без обоснования
>
> Разрешённые категории работы: рефакторинг, исправление багов, документация,
> тесты, оптимизация, уборка дублирования. После каждой задачи — git commit.

## Задачи

- [x] Проанализировать git-статус и незакоммиченные изменения на ветке autopilot (изменения в src/config, src/scenes/GameScene, src/systems/CombatCore, src/zones от предыдущих задач). Проверить каждое изменение: если оно корректно и соответствует AGENTS.md — оставить; если сомнительное или ломает игру — откатить. В конце закоммитить итог.
- [ ] Проверить, что проект собирается без ошибок: `npm run build`. Исправить любые найденные ошибки сборки или предупреждения, которые реально влияют на сборку.
- [ ] Аудит src/scenes/ на утечки памяти: таймеры и события, которые не очищаются в shutdown/cleanup. Найти и исправить (но не используй removeAllEvents() бездумно — он убивает чужие таймеры).
- [ ] Проверить src/systems/CombatCore на «buff without consumption» анти-паттерн из AGENTS.md: найти баффы, которые сеттятся, но никогда не читаются в формулах. Исправить или убрать.
- [ ] Найти в проекте захардкоженные числовые параметры (magic numbers), которые должны быть в src/config/*.js. Вынести их в конфиг по конвенции `convention-config-driven`.
